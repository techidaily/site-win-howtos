## Method 1: Take the ownership of the file or folder

 The access denied error may occur if you don’t have the ownership of the file or folder or the ownership has changed. You can try taking the ownership and see if this resolves the problem.

 Note that the steps to take the ownership on Windows 10/8 is slightly different from the steps on Windows 7\. The following part will show you how to take ownership on the these different systems.

**IMPORTANT:**  You should log on your operating system as an administrator before you go on — An administrator has the privileges to make advanced changes to the file or folder and the steps as follows require those privileges.

 If you are not clear if your account type is administrator, click the**Start** button in the lower left corner of the screen and then type “_**account**_ “.
